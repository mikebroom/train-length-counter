# Train Length Counter (Android)

Tap the "Train length" bar to set the length in feet. Press START: the app uses GPS speed to
count down the remaining feet and plays a 1-second beep when the distance has been covered.

## Build
- Android Studio: File > Open this folder, then Build > Build APK(s).
- GitHub: push this folder to a repo; the included Actions workflow builds the APK
  (download it from the run's "Artifacts").
